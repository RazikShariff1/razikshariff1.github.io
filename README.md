# razikshariff1.github.io

Personal portfolio of Razik Shariff, SDE 1 Backend at Zopping.

A single-page, dependency-free site (plain HTML, CSS and JS): aurora background, floating nav, bento grid, timeline, filterable project cards, scroll-reveal animations, and automatic light/dark theme.

## Edit
- Text and projects: `index.html`
- Colours, fonts and spacing: the variables at the top of `assets/css/style.css`
- Behaviour (filters, animations): `assets/js/script.js`
- Resume PDF: replace `assets/Razik_Shariff_Resume.pdf`
- Project thumbnails: `assets/images/`

Earlier versions were based on the vCard-style layout (MIT, see LICENSE).
