# razikshariff1.github.io

Personal portfolio of Razik Shariff, SDE 1 Backend at Zopping.

Built on the vCard-style portfolio layout used by [AnirudhPI.github.io](https://github.com/AnirudhPI/AnirudhPI.github.io) (MIT licensed, see LICENSE), recoloured with an ocean-blue palette and a light theme.

## Publish on GitHub Pages
1. Create a public repository named `razikshariff1.github.io`.
2. Upload everything in this folder to the repository root.
3. The site goes live at https://razikshariff1.github.io in a minute or two.

## Edit
- Text: `index.html`
- Colours: the variables at the top of `assets/css/style.css`, and the light theme block at the end
- Resume PDF: replace `assets/Razik_Shariff_Resume.pdf`
- Projects: add a card in the Portfolio section and a thumbnail in `assets/images/`
